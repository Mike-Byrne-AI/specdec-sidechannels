Provenance: the fusion of two sibling projects — sideband (the spec-decode
harness; its verifier math, ledger methodology, and steering findings) and
determinism-layer / lockstep (../lockstep-ultimate-repo, D-7: the integer

Stated honestly: lockstep is an lsp0 byte-alphabet trust base with no LLM
adapter yet; amber does not sit on a finished runtime, it supplies the
determinism measurement (Phase 2) that lockstep's lsp1 is blocked on. Serve-time speculative decoding IS that regime:
every generated session's divergence trace is its own archive at zero
marginal pack cost. Amber is the codec that makes the trace a file format.

## The mechanism

Regime A (flagship): content generated by the target under deterministic
decode. Archive = positions + ranks where a deterministic DRAFT replay
diverges from the target's output. Decode = replay the draft, apply
corrections. The target exists only at encode time. Determinism contract
(D-5, narrowed by F-2): the draft's token ORDERING must reproduce — rank
stability, not bitwise logits.

Attestation: L0 = header fingerprint (draft-only). L1 = with the target,
the recomputed divergence set must equal the recorded corrections; a single
forged token fails (F-2). Known L0 blind spot: order-preserving drift is
invisible (also the source of the format's quantization tolerance).

Load-bearing constraint (D-2): anything shaping the code must be
decoder-reproducible. Encoder-only signals choose hints; they never silently
reshape q.

## What v0.1.0 establishes (synthetic regime — carry the tags)

- Byte-exact roundtrip across configs; loud typed failure on corruption.
- The rate curve vs draft alignment (F-1): beats the AC-under-draft bound at
  alpha >= 0.7; 12.5x raw at alpha 0.97; loses below ~0.55; Elias-gamma
  costs a flat ~1.4 bits/token vs the format's own bound.
- The honest surprise (F-1 caveat): in this degenerate world zlib wins on
  content redundancy — the deciding quantity everywhere is divergence
  entropy vs content entropy. D-6 makes the four-way comparison mandatory.
- Attestation semantics and the rank-stability narrowing (F-2, D-5).

### Phase 2 — Rank stability audit  [OQ-2; RUN 2026-08-29: F-5/F-6 TinyLlama, F-7 Llama-3.2-1B-Instruct; band (b) both]

Decision: fp32-class decoder contract (D-8), 3.65x the bf16 replay time; escape off by default.

box: CPU fp32 is the reference "device", GPU bf16/fp16/int8/nf4 and batch

## Coder upgrade path  [DONE 2026-08-30: F-9, D-8]
Built as src/amber/rac_codec.py over lockstep.rac (D-7): flag alphabet
{A, C, T, X} with order-only contexts, log-bucket ranks, raw ids beyond R=64.
Measured: +1% over Elias-gamma on the real stream (order-only contexts carry
almost nothing gamma's gap coding does not), -40% on 250-token archives, and
the 23-27% that value contexts would buy is exactly the PMATIC hazard — so
gamma stays the default and value contexts are forbidden. F-1's "~1.4 bits
recoverable" was a property of the synthetic world (no shallow corrections
there), not a forecast. The remaining rate levers are hints (OQ-4) and
content mix, not the coder.
