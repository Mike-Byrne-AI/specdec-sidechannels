# Task-pack rules

- Active work lives only in root-level `task-packs/TP-*.md` files.
- Examples, archives, completed packs, and done packs are inactive.
- Each pack needs Goal, Why this matters, Out of scope, Files touched, Risk level, Dependencies, Proof gate, Sub-tasks, Final acceptance, and Stop conditions.
- Sub-tasks are numbered implementation phases; use `Task N-A`/`Task N-B` labels only when the pack needs per-task headings.
- A completed pack moves to `task-packs/done/` or `task-packs/completed/` with a status line prepended.
- Do not let example packs appear as active work.
