# What this repository leaves out

This repository is a fresh-history export of private research repositories; each folder's WITHHELD.md lists what that folder leaves out and what the export changed in it:

- `sideband/WITHHELD.md`
- `amber/WITHHELD.md`
- `lockstep/WITHHELD.md`

At the root, the export emits README.md, LICENSE, NOTICE, CITATION.cff, licenses/ and .github/workflows/ci.yml from authored sources kept in the private sideband repository under a withheld folder, and this file. The export tool itself and its test are withheld with the sideband folder (its WITHHELD.md says why).
