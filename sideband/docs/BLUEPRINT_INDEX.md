# docs/BLUEPRINT.md - reading-order index

docs/BLUEPRINT.md is the plan of record: dated registrations, amendments,
outcomes and errata appended in chronological order and never rewritten.
This index lists its section headings and its ALL-CAPS dated blocks in file
order, with the line each one starts on at the commit that wrote this index
(the file is append-only below its top sections, so earlier line numbers
stay valid until a dated insertion above them; the stable pointer is the
block title, which `grep -n` finds). Dated note 2026-10-16: the Line column was
regenerated by title after lane B's dated insertions (a front-matter note and
nine other notes above most blocks); tests/test_record_claims.py pins every
row's title to its stated line, so the next insertion without a regeneration
goes red there. The index is a derived reading aid,
not registered text; if it disagrees with the file, the file wins.

Suggested reading order for a newcomer: docs/REPORT.md, then
docs/FINDINGS_INDEX.md, then the blocks below in this order - the premise
and signal-flow sections; the Phase 3 existence registration and its
outcomes (F-15..F-18); the K-3 Attempt #1 arc (F-19) and its VOID
EXECUTION; the FOLD-BACK COUNT AMENDMENT; the OQ-15 stages (F-20, F-21);
the OQ-16 stages, DR-1..DR-4 (F-22), the STAGE-A FREEZE and the OQ-16
DATED ERRATUM + LANE CLOSURE (F-23); then the eval protocol and the GPU
port checklist at the end.
